# Projeto Front-End

Este projeto apresenta o desenvolvimento front-end de um site real para o consultório fonoaudiológico de Luiza Busnardo.

Ele foi criado como trabalho acadêmico para a faculdade por uma equipe de três estudantes. Apesar de ter sido desenvolvido em conjunto para fins de aprendizagem, o site representa um projeto real e demonstra o uso prático de HTML, CSS e JavaScript na construção de uma experiência completa para web.

O projeto marcou o primeiro desenvolvimento em equipe dos integrantes, com foco especial em front-end, organização visual, responsividade e interação.

## Paginas

- `index.html`: tela de login, com opção de alternar a visibilidade da senha e acesso ao cadastro.
- `cadastro.html`: formulário de criação de conta, com validação de nome, data de nascimento, CPF, telefone, endereço, login e senha.
- `inicio.html`: página institucional do consultório, apresentando a equipe, os serviços, os profissionais, os diferenciais e os canais de contato.
- `atividades.html`: área reservada por sessão para pacientes, com busca, filtros por tema e atividades sugeridas para serem realizadas em casa.

## Tecnologias

- HTML5
- CSS3
- JavaScript

O layout utiliza fontes externas do Google Fonts e recursos visuais locais armazenados na pasta `imagens`.

## Executar localmente

Abra o arquivo `index.html` em um navegador ou sirva a pasta com uma extensao de servidor local.

## Observacao

O cadastro e a autenticacao deste projeto sao demonstrativos e utilizam `localStorage` e `sessionStorage` no navegador. Eles nao devem ser usados para dados reais de pacientes ou como sistema seguro de producao.
